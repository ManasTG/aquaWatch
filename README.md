# aquaWatch
 
### Workflow
Capture Image -> ML Model Classify -> Cloudinary uploaded -> Globed (thru geo data) -> Frontend

### Techstack
- Python (logic)
- CesiumJS (Globe)
- Clip-vit-base
- React (Vite)
- FastAPI
- Cloudinary


### Run Project
- Run Backend - `uvicorn app.main:app --reload`
- Run Frontend - `npm run dev`
